# Multiplication Table - Git, GitHub, Docker and Selenium

7.a  Multiplication table program + Git/GitHub
7.b  Docker container + Selenium testing of a simple webpage

## Files
- multiplication.js : the program (works in terminal and is used by the web app)
- server.js         : small web server (no extra libraries needed)
- public/index.html : the webpage
- test.js           : unit tests
- selenium/run.js   : Selenium browser test
- Dockerfile, docker-compose.yml : Docker setup
